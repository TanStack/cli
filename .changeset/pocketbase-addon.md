Add a React PocketBase add-on. `--add-ons pocketbase` wires the PocketBase JS SDK into a TanStack Start app, with a migration for an owner-scoped `todos` collection and a `/demo/pocketbase` route with email and password sign-in and a private realtime todo list. With the ESLint toolchain, the generated config ignores PocketBase's `pb_data/` and `pb_migrations/`.
